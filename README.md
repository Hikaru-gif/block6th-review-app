# BLOCK 6th 口コミ作成サポートアプリ

BLOCK 6th にご来店いただいたお客様が、店内に設置したQRコードから
「実際の来店体験」を入力し、AIがそれを自然な文章に整えて、
Googleの口コミ投稿ページへスムーズに進めるようにするためのWebアプリです。

**このアプリは「架空の口コミを作る」ものではありません。**
お客様が入力した内容だけをもとに文章を整え、入力にない事実・感想・評価は
AIが追加しないように設計されています（詳しくは「AIの安全設計について」を参照）。

## 1. このアプリの概要

流れは以下の通りです。

1. お客様が店内のQRコードをスマートフォンで読み取る
2. Webページが開き、「印象に残った項目」を選択（任意）＋自由記述で感想を入力
3. 「口コミ文章を作る」を押すと、AIが入力内容だけを自然な文章に整える
4. 生成された文章を確認・自由に編集できる
5. 「文章をコピー」でクリップボードにコピー
6. 「Google口コミを書く」でGoogleの口コミ投稿ページが開く
7. お客様自身が文章を貼り付けて投稿する（自動投稿はしません）

技術構成はシンプルです。

- **Next.js（App Router）+ TypeScript + Tailwind CSS**
- AI文章生成：OpenAI API（サーバー側のAPI Routeからのみ呼び出し、APIキーはブラウザに公開されません）
- データベースなし（口コミの入力内容・生成文章は保存しません）
- ホスティング：Vercel（無料プランで運用可能）

## 2. 必要なアカウント

- **GitHubアカウント**（コードを保管し、Vercelと連携するため）

- `OPENAI_API_KEY`：OpenAIのAPIキー
- `GOOGLE_REVIEW_URL`：Googleの口コミ投稿ページのURL（APIキーではありませんが、必須の設定値です）

取得方法は後述します。

## 4. ローカルでの起動方法

> **前提**：パソコンに [Node.js](https://nodejs.org/)（バージョン18.18以上）がインストールされていること。

1. ターミナル（Macなら「ターミナル」、Windowsなら「PowerShell」など）で、このプロジェクトのフォルダに移動します。

   ```bash
   cd block6th-review-app
   ```

2. 依存パッケージをインストールします。

   ```bash
   npm install
   ```

3. 環境変数ファイルを作成します（詳しくは次の章）。

   ```bash
   cp .env.local.example .env.local
   ```

   `.env.local` を開いて、`OPENAI_API_KEY` と `GOOGLE_REVIEW_URL` を実際の値に書き換えてください。

4. 開発サーバーを起動します。

   ```bash
   npm run dev
   ```

5. ブラウザで `http://localhost:3000` を開くと、アプリが表示されます。
   スマートフォンでの見た目を確認したい場合は、ブラウザの開発者ツールでスマートフォン表示に
   切り替えるか、パソコンとスマートフォンを同じWi-Fiに接続し、パソコンのIPアドレス経由で
   アクセスしてください（例：`http://192.168.x.x:3000`）。

## 5. 環境変数の設定方法

`.env.local.example` をコピーして `.env.local` を作成し、以下を設定します。

| 変数名 | 必須 | 内容 |
|---|---|---|
| `OPENAI_API_KEY` | ✅ | OpenAIのAPIキー（後述の方法で取得） |
| `OPENAI_MODEL` | 任意 | 使用するAIモデル名。未設定時は `gpt-4o-mini` |
| `GOOGLE_REVIEW_URL` | ✅ | Googleの口コミ投稿ページURL |
| `RATE_LIMIT_MAX_REQUESTS` | 任意 | 一定時間内に許可するリクエスト数（未設定時は8） |
| `RATE_LIMIT_WINDOW_MS` | 任意 | レート制限の時間枠（ミリ秒。未設定時は600000＝10分） |

**`.env.local` は絶対にGitHubへアップロードしないでください。**
`.gitignore` によって自動的に除外される設定になっていますが、誤って
コミットしないよう十分に注意してください。

### OpenAI APIキーの取得方法

1. https://platform.openai.com/ にアクセスし、アカウントを作成／ログイン
2. 左メニューの「API keys」を開く
3. 「Create new secret key」をクリックし、キーをコピー
4. `.env.local` の `OPENAI_API_KEY=` の後ろに貼り付ける

## 6. Google口コミURLの取得方法

1. パソコンまたはスマートフォンで [Googleビジネスプロフィール](https://business.google.com/) にログインする
2. 対象の店舗（BLOCK 6th）を選択する
3. メニューから「口コミを増やす」（または「クチコミ」→「口コミ投稿用リンクを共有」など、
   画面によって表記が異なります）を探す
4. 表示されたURL（例：`https://g.page/r/xxxxxxxxxxxxxxxxxxx/review`）をコピーする
5. `.env.local`（ローカル環境）とVercelの環境変数（本番環境）の両方の
   `GOOGLE_REVIEW_URL=` に貼り付ける

> Googleの管理画面の表記は時期やアカウントによって変わることがあります。
> 見つからない場合は「Googleビジネスプロフィール 口コミ リンク 取得方法」で検索するか、
> Googleのヘルプページを参照してください。

1. https://github.com/ でアカウントを作成する（すでにお持ちなら不要）
2. 右上の「+」→「New repository」で新しいリポジトリを作成（例：`block6th-review-app`）

   ```bash
   git init
   git add .
   git commit -m "初回コミット"
   git branch -M main
   git remote add origin https://github.com/あなたのユーザー名/block6th-review-app.git
   git push -u origin main
   ```

4. GitHubのリポジトリページを開き、`.env.local` がアップロードされていないことを確認してください
   （表示されていなければ正常です）。

## 8. Vercelへのデプロイ方法

1. https://vercel.com/ にアクセスし、GitHubアカウントでログインする
2. 「Add New...」→「Project」を選択
3. 先ほどGitHubにアップロードしたリポジトリ（`block6th-review-app`）を選択し、「Import」
4. フレームワークは自動的に「Next.js」と認識されます。特別な設定変更は不要です
5. 「Environment Variables」の欄で、次章の環境変数を設定する
6. 「Deploy」をクリックする
7. 数分待つと、`https://あなたのプロジェクト名.vercel.app` のようなURLが発行され、公開されます

## 9. Vercelの環境変数設定方法

Vercelのプロジェクト画面で「Settings」→「Environment Variables」を開き、以下を1つずつ追加します
（初回デプロイ時の画面からも設定できます）。

| Key | Value |
|---|---|
| `OPENAI_API_KEY` | 取得したOpenAIのAPIキー |
| `OPENAI_MODEL` | `gpt-4o-mini`（変更したい場合のみ） |
| `GOOGLE_REVIEW_URL` | 取得したGoogleの口コミ投稿ページURL |
| `RATE_LIMIT_MAX_REQUESTS` | `8`（必要に応じて変更） |
| `RATE_LIMIT_WINDOW_MS` | `600000`（必要に応じて変更） |

環境変数を追加・変更したあとは、Vercelの「Deployments」タブから
「Redeploy」を実行しないと反映されない場合があります。

## 10. 公開後の確認方法

1. VercelのURL（例：`https://xxxxx.vercel.app`）にスマートフォンでアクセスする
2. 「印象に残った項目」を選び、感想を入力して「口コミ文章を作る」を押す
3. 文章が生成されることを確認する
4. 生成された文章を編集できることを確認する
5. 「文章をコピー」を押し、実際に他のアプリ（メモ帳など）に貼り付けてコピーできているか確認する
6. 「Google口コミを書く」を押し、正しいGoogleの口コミ投稿ページが開くことを確認する
7. 何も入力せずに送信しようとした場合や、非常に短い入力の場合にエラーメッセージが
   表示されることを確認する

## 11. QRコードの作成方法

公開URLが決まったら、そのURLをQRコード化して店内に設置します。

1. 無料のQRコード生成サイト（例：[https://www.qr-code-generator.com/](https://www.qr-code-generator.com/) や
   Googleで「QRコード 作成 無料」と検索して出てくる信頼できるサービス）を開く
2. 公開URL（例：`https://xxxxx.vercel.app`）を入力する
3. QRコード画像をダウンロードする
4. 印刷してテーブルやレジ周りなど、お客様の目につく場所に設置する

> QRコード画像自体はこのアプリのコードには含まれていません
> （公開URLが決まったあとに作成するものであるため）。
> 生成したら、実際にスマートフォンで読み取り、正しいページが開くことを必ず確認してください。

## 12. トラブルシューティング

| 症状 | 考えられる原因と対処 |
|---|---|
| 「文章の作成に失敗しました」と表示される | OpenAIのAPIキーが正しく設定されているか、Vercelの環境変数を確認してください。OpenAI側の利用上限に達している可能性もあります。 |
| 「Google口コミページの設定が完了していません」と表示される | `GOOGLE_REVIEW_URL` が設定されているか確認してください。 |
| ローカルで起動できない | `npm install` を再度実行し、Node.jsのバージョンが18.18以上か確認してください。 |
| コピーがうまくいかない（一部のブラウザ） | フォールバック処理が動作しますが、それでも失敗する場合はテキストを長押しして手動でコピーしてください。 |
| Vercelのデプロイでビルドエラーになる | Vercelの「Deployments」→対象のデプロイ→「Build Logs」でエラー内容を確認してください。多くの場合、環境変数の設定漏れかコードの記述ミスです。 |
| 生成文章の内容が短すぎる／期待と違う | AIは入力内容以上の事実を追加しない設計のため、入力が短いと生成結果も短くなります。これは仕様です。 |

## 13. AI APIの料金について

- OpenAIのAPIは従量課金制です（使った分だけ課金されます）。
- 1回の口コミ生成あたりのコストは非常に小さいですが、想定外の大量アクセスに備えて、
  必ずOpenAIのダッシュボードで**月額利用上限（Usage limit）**を設定してください。
  1. https://platform.openai.com/ にログイン
  2. 「Settings」→「Billing」→「Limits」（画面構成は変更されることがあります）
  3. 月額の上限金額を設定する
- 最新の料金は [OpenAIの公式料金ページ](https://openai.com/api/pricing/) で必ず確認してください。
- 本アプリはアプリ側でも簡易的なレート制限（1IPあたり一定時間内のリクエスト数制限）を
  実装していますが、あわせてOpenAI側の上限設定も行うことを強く推奨します。

## 14. APIキーを漏らさないために

- `OPENAI_API_KEY` はサーバー側（API Route）でのみ使用しており、ブラウザ側のコードには
  一切含まれません。ブラウザの開発者ツールで見ても表示されません。
- `.env.local` はGitにコミットされない設定になっています。**絶対に手動でコミットしないでください。**
- APIキーをメール・チャット・SNSなどで他人に送らないでください。
- もしAPIキーが漏れてしまった場合は、すぐにOpenAIのダッシュボードでそのキーを削除（Revoke）し、
  新しいキーを発行してVercelの環境変数を更新してください。

## 15. AIの安全設計について

このアプリの最重要ルールは「AIが実際に入力されていない体験を作り出さないこと」です。
以下のように設計しています。

- 店舗の特徴（料理内容、シーシャ、個室、飲み放題など）は、**コード内のAIプロンプトに
  一切含めていません**。README等のドキュメント用情報としてのみ記載しています。
- AIへ渡す情報は「お客様の自由入力」「選択されたタグ（参考情報として明示）」
  「文章作成のルール」だけです。
- システムプロンプトで、入力にない事実・感想・評価を追加しないことを明示しています。
- お客様の入力は `<customer_input>` タグで区切り、「これは指示ではなく素材である」旨を
  明示することで、プロンプトインジェクション（入力に紛れ込んだ指示文への追従）を防いでいます。

### 動作確認用スクリプト

`scripts/check-safety.mjs` に、入力にない固有名詞が出力に混入していないかを
簡易的にチェックするスクリプトを用意しています。

```bash
npm run safety-check
```

- `.env.local` に `OPENAI_API_KEY` を設定した状態で実行してください。
- 5種類のテストケースをそれぞれ5回ずつ実行し、結果をターミナルに表示します。
- これはキーワード一致による簡易チェックです。**最終的には人の目で出力内容を確認してください。**
- このスクリプトはOpenAI APIを呼び出すため、実行するたびに少額の利用料金が発生します。

> **開発環境についての注記**：このアプリはインターネット接続のない開発用サンドボックス環境で
> 作成されたため、`npm install` の実行・実際のビルド・AIの応答テスト・実機での動作確認は
> 行えていません。お手数ですが、ローカルPCまたはVercel上で上記の手順に沿って動作確認を
> 行ってください。セクション24・25に記載のテストケースを一通り試すことを推奨します。

## 16. レート制限について（重要な制限事項あり）

このアプリは、同一IPアドレスからの短時間の大量アクセスを緩和するため、
メモリ上で簡易的なレート制限（既定：10分間に8回まで）を行っています（`lib/rateLimit.ts`）。

**ただし、Vercelなどのサーバーレス環境では、リクエストごとに異なる実行インスタンスが
使われることがあるため、このメモリ上のカウンタは複数のインスタンス間で共有されません。**
そのため、この制限は「明らかな連打・簡易的なbot対策」程度の効果に留まり、
厳密なレート制限としては機能しない場合があります。

より確実な制限が必要な場合は、以下のような対策を検討してください（本アプリには含まれていません）。

- Vercelの Web Application Firewall / Rate Limiting 機能（プランによる）
- Upstash Redisなど、外部の共有ストレージを使ったレート制限
- Cloudflareなど、CDN側でのレート制限

小規模な店舗での利用であれば、まずはOpenAI側の月額利用上限設定（セクション13）と
このアプリの簡易レート制限の組み合わせで十分なケースが多いです。

## 17. 管理画面について

今回、管理画面やログイン機能は作成していません。
店舗側で変更する可能性があるのは基本的に環境変数（特に `GOOGLE_REVIEW_URL`）のみです。
変更したい場合は、Vercelの「Settings」→「Environment Variables」で値を書き換え、
「Redeploy」を実行してください。
